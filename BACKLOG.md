# Backlog

De backlog staat nu in GitHub Issues: <https://github.com/jeroenniesen/EnergyManagementSystem/issues?q=is%3Aissue+is%3Aopen+label%3Abacklog>

De volgorde wordt bepaald door de `prio:*`-labels en de regel `_Volgorde in backlog: #N_` in elk issue. Elke issuetitel draagt het oude B-nummer (bijvoorbeeld `[B-09] ...`) zodat het herleidbaar blijft.

Het oude bestand blijft in de git-geschiedenis. De laatste versie staat op commit `00ed087aa7a06ee3e9a83164e63563a7eb7418fc`.
